## Hi, we are Topraklık Game Dev Studio 👋

A small independent game studio from Türkiye. We make games and tools, and we share some of our work for free.

### Projects

- **[TLD Shared World](https://github.com/TopraklikGameDevStudio/TLD-Shared-World)**: a free, open-source co-op mod for *The Long Dark* where you and your friends play in one truly shared world. English and Turkish.
